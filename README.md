# 🥬 FreshNess – Organic E-commerce App

FreshNess is a modern and responsive **organic grocery e-commerce web application** built using **HTML**, **Tailwind CSS**, and **JavaScript**.  
It features a clean and modern UI, product filtering, category navigation, and attractive promotional sections.

## 📌 Features

- ✅ **Responsive Navbar** (Mobile + Desktop)
